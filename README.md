# learndev

An interactive in-browser tool for learning software development concepts through guided stages.

## Files

```
learndev/
├── index.html    — HTML shell, loads styles and scripts
├── style.css     — CSS variables and all visual styling
├── engine.js     — Runtime logic: rendering, input handling, stage progression
├── content.js    — All learning content; exports STAGES array consumed by engine
├── assets/       — Static assets (images, icons, etc.)
└── README.md     — This file
```
